The procedure

Six rounds, one reconcilable answer

The reconciliation is a protocol, not a prompt. Each round has a defined entry condition, a defined output, and an append-only record. Replay it as often as you like — it is deterministic.

01 Independent analysis

Each agent runs its own forward-chaining reasoner over the same fact base and produces a ranked leaderboard. They do not see each other's output.

Disagreement here is a consequence of different rules and weights, not different data.

02 Cross-examination

Each agent attacks the other's pick with a cited reason: protocol, evidence, population, organ, toxicity, or a counterfactual on the weight vector.

Every challenge carries the citation it rests on. Opinion without provenance is not accepted.

03 Sensitivity & frontier

Each agent's pick is re-scored under the other's weights to expose where the disagreement is a factual dispute and where it is a policy choice.

A log-pooled compromise is then computed — and it is shown, including the criteria it cannot pool.

04 Concession exchange

Each agent states the minimum set of conditions under which it would accept the other's therapy. A satisfiability test runs the composite plan against every one.

Unmet conditions are carried into the escalation. They are never quietly dropped.

05 Reconciliation

The protocol produces exactly one of four shapes: consensus, guarded adoption (innovation accepted only inside the conservative agent's scaffolding), a documented refusal, or escalation.

An explicit trade-off ledger is emitted: position 1, position 2, resolution.

06 Safety overlay & seal

Hard gates are re-evaluated after the negotiation, then toxicity ceilings, consent obligations and stop-rules. The transcript is sealed with a SHA-256 chain.

Disagreement is permitted to be total. It is never permitted to be permissive.

Why it is auditable

Four Omega capabilities, used as the feature

The track asks for MeTTa's identity — reasoning, self-modification, memory, symbolic logic — to be the product, not the homework. Each of these is load-bearing. Remove one and the demo does not degrade; it stops working.

Auditable reasoning

A forward-chaining reasoner over MeTTa-style atoms. Every derived atom stores the rule that fired it and the exact premises consumed.

Try it: click any transcript step, then Show provenance. You get the rule id, its premises, and the chain back to raw case facts.

Self-modification

A reviewer input is compiled into new hard rules injected symmetrically into both agents. The literal before/after rule diff is displayed line by line.

Try it: veto a therapy in the console. Watch Δ rule base gain a rule, then watch the verdict change.

Stateful memory

Adjudications persist to localStorage and reload as precedent, signed into the seal. Run a case twice and the second run cites the first.

Try it: run CV-2291, switch to CV-3310, come back. The precedent is recalled and the confidence term shows it.

Symmetric constraint

The four hard rules are structurally identical in both agents. Whatever the agents disagree about, neither can trade away an absolute contraindication.

Governance claim: a reviewer who constrains the innovative agent is constraining the cautious one in the same breath. Asymmetric control is not a safety feature.

Confidence, shown as arithmetic

Never assert a number. Show the sum.

Every verdict carries a confidence figure and the terms that produced it. Below 70% the system refuses to recommend autonomously and escalates. Above 94% it refuses on principle — no autonomous system should be more certain than that.

Below 70%

Escalate, do not guess

The protocol returns no therapy. The transcript becomes the deliverable: a clinician receives the full disagreement, the thresholds, and the unmet conditions.

70 – 78%

Consensus with obligations

A plan is returned, but capped where an off-label component is present. Consent, MDT sign-off, published stop-rules and a reachable fallback all attach.

78 – 94%

Plan of record

Both agents can live with it. First assessment is pre-registered with a switch trigger, so the plan stays reversible at the first checkpoint.

Hard stop

The gate is not negotiable

Contraindications are evaluated after the negotiation, by a layer neither agent can address. Refusing to treat is a success state, not a failure state.

A second opinion you cannot interrogate is not a second opinion. It is a second opinion you have to trust — which is exactly where you started.
